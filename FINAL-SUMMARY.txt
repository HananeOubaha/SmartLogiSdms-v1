🎯 PIPELINE JENKINS - 10 ÉTAPES

1. 📋 Préparation
   → Clone dépôt + Nettoyage workspace

2. 🔨 Compilation
   → mvn clean compile
   → Vérification dépendances

3. 🧪 Tests Unitaires
   → mvn test (JUnit 5 + Mockito)
   → H2 Database

4. 📊 Couverture de Code
   → mvn jacoco:report
   → Rapport HTML/XML

5. 🔍 Analyse SonarQube
   → mvn sonar:sonar
   → Détection bugs/failles

6. ⚖️ Quality Gate
   → Vérification seuils
   → Blocage automatique si échoué

7. 📦 Build Package
   → mvn package
   → JAR exécutable

8. 🐳 Build Docker
   → docker build
   → Multi-stage optimization

9. 📤 Push Docker (Optionnel)
   → docker login
   → docker push

10. 📚 Archivage
    → Artefacts + rapports
    → Historique builds
